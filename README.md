# Cursor Freeload

## 1. 功能

针对Cursor IDE使用次数限制的一种解决方案，此项目仅用于学习使用，建议购买正版付费。

## 2. 打包

`yarn && yarn package`

## 3. 打包后使用

- web登录界面删除账户信息
- Cursor IDE 退出账户登录
- `Ctrl + shift + P` > `Cursor Freeload`
- 重启IDE并登录

## 4. 常见问题

1. 找不到Cursor程序？
   - 检查Cursor是否已正确安装
   - 检查默认安装路径
   - 如果是自定义安装路径，请在设置中配置`customCursorPath`

2. 权限不足？
   - 按照提示授予必要的文件访问权限
   - Windows用户可能需要以管理员身份运行VSCode
   - macOS/Linux用户可能需要输入管理员密码

3. 操作后无法启动Cursor？
   - 检查是否有其他Cursor进程正在运行
   - 尝试重新安装Cursor
   - 恢复已自动备份的原始文件（文件名后缀为.backup）
